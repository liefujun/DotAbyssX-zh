📖 安装说明
  1. 下载最新版本的 .apk 文件并安装（包名为 jp.co.fanzagames_dotabyss_x_a.mod，可与官方原版共存）。
  2. 首次启动黑屏 1~3 分钟属正常现象（LemonLoader 正在部署翻译数据）。
  3. 如之前装过旧版汉化并出现 "NativeLoader.load failure"，删除 Android/data/jp.co.fanzagames_dotabyss_x_a.mod/files/MelonLoader/ 目录后重新启动即可。
📦 UnityCache 资源缓存使用方法（可选，节省游戏内下载流量）
  1. 下载全部 4 个分卷：UnityCache.zip.part01 ~ part04，放在同一目录。
  2. 合并分卷：

Windows（cmd）：

copy /b UnityCache.zip.part01 + UnityCache.zip.part02 + UnityCache.zip.part03 + UnityCache.zip.part04 UnityCache.zip

Android / Linux：

cat UnityCache.zip.part01 UnityCache.zip.part02 UnityCache.zip.part03 UnityCache.zip.part04 > UnityCache.zip
  1. 解压 UnityCache.zip，将 UnityCache 文件夹复制到：
    /sdcard/Android/data/jp.co.fanzagames_dotabyss_x_a.mod/files/UnityCache/

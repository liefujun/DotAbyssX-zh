# DotAbyss X (ドットアビスX) 安卓端简体中文汉化版



基于官方版集成社区简体中文翻译（LemonLoader + AbyssMod），包名独立，可与官方原版共存。



## 📥 下载



**[➡️ 点击进入下载页面](https://liefujun.github.io/DotAbyssX-zh/)**



安装包按版本排序，UnityCache 资源缓存单独列出，均在下载页面获取。



## 最新版本



**v1.16.1**（2026-11-11）：适配官方 1.16.1 代码热修；全角色名已补齐中文（新增 奥蕾莉亚 / 薇丝贝拉 等）；H 场景黑屏修复与 1.16.0 翻译沿用。
